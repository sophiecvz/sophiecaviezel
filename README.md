# 🤍 Sophie Caviezel

a minimal, responsive personal landing page for Sophie Caviezel, featuring a profile portrait, a primary external link, and social media links

## tech stack

- HTML5
- CSS3
- JavaScript
- Vite 8
- npm
- Prettier

built with native HTML, CSS, and minimal vanilla JavaScript, without a frontend framework

## requirements

- Node.js 24 LTS
- npm

the Node.js version is specified in [`.node-version`](.node-version)

## getting started

install dependencies:

```bash
npm ci
```

start the development server:

```bash
npm run dev
```

## available scripts

| command                | description                              |
| ---------------------- | ---------------------------------------- |
| `npm run dev`          | start the development server             |
| `npm run build`        | create a production build in `dist/`     |
| `npm run preview`      | preview the production build locally     |
| `npm run format`       | format files with Prettier               |
| `npm run format:check` | check formatting without modifying files |
